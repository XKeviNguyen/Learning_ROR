# Learning_ROR

A small Ruby on Rails API project used to practice production-minded Rails development.

> This repository is maintained as a current portfolio/learning project. Its Git history reflects when changes were actually made.

## Project: Reading List API

A REST-style API for managing books and reading status.

### Goals

- Keep controllers thin and validation in the model layer
- Use PostgreSQL in development/production
- Add request tests for the API
- Add CI for linting, security checks, and tests
- Keep secrets out of the repository

### Planned endpoints

- `GET /api/v1/books`
- `GET /api/v1/books/:id`
- `POST /api/v1/books`
- `PATCH /api/v1/books/:id`
- `DELETE /api/v1/books/:id`

## Development

This project is being rebuilt incrementally using issues, feature branches, pull requests, and CI so the repository documents the engineering process as well as the code.
